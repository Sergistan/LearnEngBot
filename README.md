# [“Чат-бот для изучения и перевода английских слов”](https://github.com/Sergistan/LearnEngBot)

## Описание

Проект предоставляет из себя чат-бот реализованный через Telegram для изучения и перевода английских слов.
В проекте используется API для получения случайных английских слов через: https://api-ninjas.com/api/randomword, а также 
API для перевода слов с английского на русский и с русского на английский через https://yandex.cloud/ru/docs/translate/api-ref/Translation/translate.

## Функционал и основные команды проекта:
- /start: для получения стартового сообщения пользователю от чат-бота;
- /help: для получения справочной информации пользователю от чат-бота;
- /random: для получения случайного английского слова с переводом. После нажатия команды /random необходимо выбрать одну из представленных частей речи NOUN (существительное), VERB (глагол), ADJECTIVE (прилагательное), ADVERB (наречие) нажатием кнопки в интерфейсе чат-бота. После этого мы получаем перевод формата: "перевод случайного слова на русском языке" - "случайное слово на английском языке". Затем в чате появляются 2 кнопки: LEARN (запомнить) и MISS (не запоминать). При нажатии LEARN слово с переводом сохранить в бд и будет относиться к этому пользователю для дальнейшего изучения и запоминания, а при нажатии MISS слово с переводом сохраняться в бд не будет;
- /practice: для повторения ранее добавленных английских слов с переводом. После нажатия команды /practice в чат-боте будет выведены все слова, которые пользователь сохранил у себя до этого нажатием кнопки LEARN в формате: "русское слово" - "перевод на английском языке";
- /delete: для удаления слова из списка ранее сохраненных слов у пользователя. Выполняется команда /delete и затем пишется в чат-боте английское слово, которое необходимо удалить из сохраненных слов;
- Также есть возможность просто ввести любое русское слово (существующее и орфографически правильное) в чат-боте для того, чтобы получить его перевод в формате: "русское слово" - "перевод на английском языке", после чего также возникает возможность выбрать запомнить (LEARN) или не запоминать слово (MISS);
- При наличии сохраненных слов у пользователя приложение само раз в сутки будет отправлять уведомление в чат-бот со списком всех сохраненных слов для их повторения.

## Основные технологии:

- Приложение разработано с использованием Spring Boot 3 и Java 17;
- Использован сборщик пакетов Gradle;
- Использована sql-база данных PostgreSQL;
- Используется Scheduled для уведомления пользователей;
- Используются сторонние API для работы приложения;
- Использован словарь Hunspell для проверки слов на орфографию и их существование;
- Для запуска используются Dockerfile и docker-compose;
- Приложение было протестировано и запущено на удаленном сервере для непрерывной работы через Telegram.
